# Project layout templates

Reference trees for the four shapes rs-structure recommends. Copy the tree,
rename features, and write a Design Contract (with **Layout**) in every `mod.rs`/`lib.rs`.

| File | Shape |
|---|---|
| `lib.md` | library crate |
| `bin.md` | binary with a library (CLI/tools) |
| `service.md` | hexagonal service |
| `workspace.md` | multi-crate workspace |

Full guidance: `skills/rs-structure/guides/layouts.md`.
