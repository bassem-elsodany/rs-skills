# Changelog

All notable changes to rs-skills. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow SemVer.

## [1.0.0] - 2026-11-11

First public release.

- 62 skills in four layers (mechanics, design, domain, delivery) plus the entry skills `rs-router` and `rs-guide`, with 400+ depth rules.
- Gates: reuse-first (SDK scout), ports and adapters, feature-module structure, a Design Contract header in every `.rs` file, security review, fuzzing, bug-fix discipline, review reports by day, release gate, build and disk cleanup, git lifecycle without AI trailers.
- 11 agents, 31 slash commands, 5 hooks (Claude Code); an installer for other agents (`scripts/install-agents.sh`).
- Self-checks: quality, rules, patterns, guide catalogue, plugin validator, compile-checked rule examples (`checks/`), CI workflow.
- Licence notices for adapted material are in `NOTICE.md`.
